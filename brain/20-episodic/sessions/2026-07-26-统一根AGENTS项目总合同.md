# 2026-07-26 · 统一根 AGENTS 项目总合同

## 目标

将此前分散在六个模块目录的 `AGENTS.md` 收敛为仓库根唯一项目总合同，明确技术基线、目录导向和团队角色分工。

## 做了什么

1. 重写根 `AGENTS.md`：补入已从真实配置核对的 Java 17、Spring Boot 3.2.4、Spring Cloud、React、TypeScript、Vite 等基线。
2. 在总合同中统一声明流量边界、数据分层、服务职责、目录地图、六类工作角色、AI 启动协议和验证命令。
3. 删除五个后端服务及前端目录共六份嵌套 `AGENTS.md`。
4. 将目录特定检查统一交给 `.agents/skills/` 中带 `paths` 的 Skills。
5. 更新 current-focus、project-map、constitution、memory-map、daily-usage 及相关 Skill 指针。

## 关键决策

- [[ADR-0006-唯一根AGENTS项目总合同]]：修正 ADR-0004 的嵌套入口部分，其余 inbox 与入口去重决策继续有效。

## 为什么

LinkedAgent 是一个产品仓和一套统一架构。嵌套入口与已有 Skills 职责重叠，且会让 JDK、端口和角色约束分散维护。根合同负责稳定全局约束，Skills 负责目录情境化护栏，边界更清晰。

## 遗留 / 下一步

- 后续升级技术基线或端口分配时同步更新根 `AGENTS.md`。
- `.agent/skills/` 下的 openspec Skills 仍按用户决定暂不迁移。
