# `--server.address=127.0.0.1` 时必须同步固定 Nacos discovery IP

## 结论

本地用 `--server.address=127.0.0.1` 防端口抢占时，若未设置 `spring.cloud.nacos.discovery.ip=127.0.0.1`，Nacos 可能注册成局域网/WSL IP（如 `172.22.16.1`）。网关按注册地址反连会 `Connection refused`，前端经 Vite→网关的 `/api/**` 全 500。

## 为何重要

症状像「前端坏了 / 白屏 / 聊天连不上」，根因在服务发现 IP 与监听地址不一致，直连 `:8082` 正常、经 `:8080` 失败即可确认。

## 如何复用

1. 各服务 `application.yml` 已写死 `spring.cloud.nacos.discovery.ip: 127.0.0.1`（与本地绑定配套）。
2. 排障：对比 `curl 127.0.0.1:8082/...` vs `curl 127.0.0.1:8080/...`；查网关日志是否 `Connection refused: /172.x.x.x:port`。
3. 启动手册：`ONE_CLICK_START.md`。

## 证据摘录

> `Connection refused: getsockopt: /172.22.16.1:8082`（api-gateway）  
> 修复后注册：`customer-service 127.0.0.1:8082 register finished`
