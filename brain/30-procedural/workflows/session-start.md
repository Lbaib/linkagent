# 工作流：会话启动（Session Start）

> 正式动手前执行。目标：最少上下文恢复「我是谁、做到哪了」。

## 步骤

1. **恢复焦点**（必做）：读 [[current-focus]]。
2. **校准落盘规则**（必做）：确认理解 [[memory-map]]（inbox 优先、情景只追加）。
3. **按需加载**：
   - 动架构 → `10-semantic/decisions/` + [[constitution]] + [[system-overview]]
   - 不熟模块 → 根 `AGENTS.md` 的目录导向 + [[project-map]]；目录特定检查由相关 Skill 自动加载
   - 规格变更 → [[spec-driven-flow]]
4. **扫悬案**（推荐）：[[open-questions]]；inbox 积压可看 [[收件箱]]。

## 反模式

- ❌ 跳过 current-focus 直接开工。
- ❌ 通读整个 brain/（按需加载）。
