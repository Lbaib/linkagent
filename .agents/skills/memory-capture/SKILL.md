# memory-capture — 知识沉淀

## 何时使用

- 用户明确说「记一下」「沉淀」「存起来」。
- 对话中自然产生了可复用结论：踩坑原因与解法、性能数据、接口约定、选型对比结果。
- 判断标准：**三个月后的自己或另一个 AI 会需要这条信息吗？** 是 → 沉淀；只是当下的中间步骤 → 不沉淀。

## 步骤

1. 把结论压成一句话标题（一篇一题）。标题要能独立看懂，不要「关于那个问题」这类指代。
2. 写入 `brain/_inbox/YYYY-MM-DD-短标题.md`，结构：

```markdown
---
type: inbox
created: YYYY-MM-DD
status: pending
tags: [收件箱]
---

# 一句话结论

## 结论
## 为何重要
## 如何复用
```

3. 可套用 `brain/_templates/知识笔记.md`。
4. 告诉用户已写入哪个文件，提醒稍后按 `brain/00-core/memory-map.md` 归档。

## 关键约束

- **不确定该归到哪一层，就留在 `_inbox/`**。捕获和分类是两件事，别在捕获时纠结分类。
- 一篇一题。两个不相关的结论写两个文件。
- 禁止写入密钥、令牌、生产连接串。
- 不要把大段源码复制进笔记，用仓库相对路径指过去。
